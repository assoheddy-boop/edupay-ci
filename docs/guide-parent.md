# Guide parent — EduConnect

Suivez la scolarité de vos enfants : paiements, absences, devoirs et messages. L’enfant n’a pas de compte.

Site : [https://educonnect-ci.com](https://educonnect-ci.com)

> **Ce dont vous avez besoin**
> Le **code école**, le **matricule** et le **nom de famille** de l’élève — demandés à l’établissement.

## 1. Créer un compte et se connecter

1. Ouvrez [https://educonnect-ci.com/auth/register](https://educonnect-ci.com/auth/register).
2. Choisissez l’onglet **Parent**.
3. Renseignez prénom, nom, e-mail, téléphone et mot de passe.
4. Ensuite, connectez-vous sur [https://educonnect-ci.com/auth/login](https://educonnect-ci.com/auth/login), onglet **Parent**.

Déjà inscrit ? Allez directement à la connexion.

## 2. Lier un enfant

Sur l’accueil, le formulaire **Ajouter un enfant** demande trois champs :

1. **Code école** (fourni par l’école, par exemple `ecole-exemple`).
2. **Matricule** de l’élève.
3. **Nom de famille** de l’élève, **exactement** comme à l’école.

Appuyez sur **Lier**.

Messages d’erreur fréquents :

- code école invalide → vérifiez le code auprès de l’école ;
- aucun élève avec ce matricule → vérifiez le matricule ;
- le nom ne correspond pas → respectez l’orthographe du nom de famille ;
- déjà lié → l’enfant est déjà sur votre compte.

Vous pouvez lier plusieurs enfants, y compris dans des écoles différentes.

## 3. Consentement (confidentialité)

Dès la première connexion, un bandeau **Confidentialité** apparaît. L’école a besoin de votre accord pour le suivi scolaire.

- **J’accepte** : vous donnez l’accord pour le traitement des données.
- **Plus tard** : vous pourrez répondre ensuite.
- **Gérer les consentements** : photos, santé, communications — menu **Confidentialité**.

Vous pouvez modifier ces choix à tout moment.

## 4. Paiements Wave et Orange Money

Menu **Payer**.

1. Vous voyez les numéros **Wave** et **Orange Money** de l’école.
2. Payez dans l’application Wave ou Orange Money, en **FCFA**.
3. Revenez sur EduConnect. Saisissez le montant, une référence (optionnel), et joignez la **capture d’écran**.
4. **Envoyer la preuve de paiement**.

Le statut passe en attente. L’école valide ou refuse. Vous êtes informé. L’historique reste visible.

> **À retenir**
> L’argent circule dans Wave ou Orange Money, pas dans EduConnect. EduConnect enregistre la preuve pour l’école.

## 5. Absences et retards

Sur l’**accueil**, chaque enfant a un résumé : paiements récents, notes, **absences**.

Le menu **Suivi** complète le quotidien (selon ce que l’école a activé) : transport, cantine, badges, santé…

Si l’enseignant marque **Retard** ou **Absent**, vous recevez une notification. Un SMS n’est envoyé que si l’école a activé le SMS officiel.

## 6. Devoirs et contrôles

Menu **Devoirs & contrôles** : calendrier et liste (devoir ou contrôle, matière, date, consignes, fiche jointe si l’enseignant en a mis une).

L’enfant n’a pas besoin d’écran : vous relayer.

## 7. Messages

Menu **Messages** : écrivez à l’école ou à l’enseignant. Vous pouvez joindre un fichier ou un vocal, et indiquer l’enfant concerné.

Ce n’est pas WhatsApp. Les échanges restent dans EduConnect.

## 8. La cloche de notifications

En haut à droite, l’icône **cloche** ouvre les notifications (absences, paiements, devoirs…). Un chiffre indique les messages non lus.

Menu **Notifications** : liste complète. Vous pouvez tout marquer comme lu.

## 9. Sur téléphone

Le bouton **trois barres** en haut à gauche ouvre le menu (Payer, Suivi, Devoirs, Messages…).

Astuce : dans le navigateur, **Ajouter à l’écran d’accueil**. EduConnect s’ouvre comme une petite application.

Si le réseau tombe après une première visite en ligne, l’envoi de la **capture de paiement** peut rester en attente, puis partir tout seul au retour de la 4G. Lier un enfant et envoyer un message demandent internet.
