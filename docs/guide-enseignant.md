# Guide enseignant — EduConnect

Mode d’emploi pour la classe : appel, notes, devoirs et messages aux parents.

Site : [https://educonnect-ci.com](https://educonnect-ci.com)

> **Avant de commencer**
> Demandez le **code école** à la direction. Sans classe assignée, l’accueil affiche « Aucune classe assignée ».

## 1. Connexion

**Si la direction vous a créé un compte** : [https://educonnect-ci.com/auth/login](https://educonnect-ci.com/auth/login), onglet **Enseignant**, puis e-mail et mot de passe reçus.

**Si vous vous inscrivez vous-même** :

1. [https://educonnect-ci.com/auth/register](https://educonnect-ci.com/auth/register), onglet **Enseignant**.
2. Saisissez vos infos et le **code école**.
3. Connectez-vous ensuite via l’onglet **Enseignant**.

Sur téléphone, le bouton **trois barres** en haut à gauche ouvre le menu.

## 2. Accueil et classes

L’accueil montre vos **classes assignées** et les notes récentes.

Menu **Élèves** : liste par classe, avec le matricule.

Les actions rapides (saisir une note, publier un devoir, messages…) dépendent des modules activés par l’école.

## 3. Appel du jour — Présent / Retard / Absent

Menu **Appel**.

1. La liste de la classe s’affiche, un élève par ligne.
2. Pour chacun : **Présent**, **Retard** ou **Absent**.
3. **Enregistrer l’appel**.

Les parents sont notifiés en cas d’absence ou de retard (dans l’application). Un SMS part seulement si l’école a le **SMS officiel** activé.

Vous pouvez aussi **signaler une absence** hors appel (menu lié, motif).

## 4. Notes

Menu **Notes** : saisie pour toute la classe (une matière, une note par élève).

Vous pouvez aussi saisir une note unitaire depuis l’accueil (**Saisir une note**).

Les parents voient les notes dans leur espace.

## 5. Devoirs et contrôles

Menu **Devoirs & contrôles**.

1. Choisissez la classe, la matière, le type (**Devoir** ou **Contrôle**).
2. Titre, consignes, date.
3. Cochez le rappel la veille au soir (18 h Abidjan) si besoin, ou un rappel personnalisé.
4. Joignez une fiche (PDF ou image) si utile.
5. **Publier**.

Un calendrier affiche les publications. Les parents sont notifiés dans l’application (SMS seulement si l’école l’a activé).

## 6. Messages aux parents

Menu **Messages** : conversations avec les familles. Texte, fichier ou vocal. Vous pouvez préciser l’enfant concerné.

Les messages ne sont pas des SMS. Ils restent dans EduConnect.

La **cloche** en haut à droite ouvre vos notifications.

## 7. Emploi du temps

Menu **Emploi du temps** : calendrier des créneaux de l’école. Consultez-le pour vos cours.

Selon l’école, d’autres menus peuvent apparaître : transport, cantine, comportement, santé, espace RH.

## 8. Hors-ligne — ce qui marche vraiment

Après une **première connexion avec du réseau**, sur le **même téléphone** :

- l’**appel** (Présent / Retard / Absent) peut être enregistré sans internet ;
- les **notes** (y compris en lot) et les **devoirs** aussi.

Un bandeau indique « en attente de synchronisation ». Quand la 4G revient, tout part tout seul. Les notifications aux parents partent **à ce moment-là**, pas pendant la coupure.

Ce qui demande encore internet : première connexion, messages, et tout ce qui n’est pas dans la file d’attente.

Conseils :

- menu du navigateur → **Ajouter à l’écran d’accueil** ;
- ne videz pas les données du site ;
- ne changez pas de téléphone au milieu d’une file : l’enregistrement est sur cet appareil.
