# Guide direction — EduConnect

Mode d’emploi pour la directrice ou le directeur d’un établissement. Les menus visibles dépendent des modules activés pour votre école.

Site : [https://educonnect-ci.com](https://educonnect-ci.com)  
Connexion : [https://educonnect-ci.com/auth/login](https://educonnect-ci.com/auth/login) — onglet **École**.

> **En une phrase**
> Vous pilotez classes, élèves, paiements Wave / Orange Money, messages et (selon les modules) devoirs, comptabilité, SMS et réinscriptions.

## 1. Connexion

1. Ouvrez [https://educonnect-ci.com/auth/login](https://educonnect-ci.com/auth/login).
2. Choisissez l’onglet **École**.
3. Saisissez votre e-mail et votre mot de passe.
4. Vous arrivez sur le tableau de bord.

Sur téléphone, le bouton **trois barres** en haut à gauche ouvre le menu.

## 2. Tableau de bord

L’accueil affiche le nom de l’école, le **code école** (à donner aux parents et aux enseignants), le nombre de classes, d’élèves, d’enseignants, et les **paiements en attente**.

Un encart d’analyse pédagogique résume effectifs, absences et réinscriptions. Le bouton **Voir les graphiques d’analyse** ouvre le détail.

Le code école est aussi dans **Paramètres**.

## 3. Classes et élèves

Menu **Classes** : créez une classe (nom, niveau, année scolaire), par exemple CM2 A.

Menu **Élèves** :

- ajoutez un élève (prénom, nom, matricule, classe) ;
- ou importez un fichier CSV (modèle téléchargeable). Créez d’abord au moins une classe.

Le **matricule** et le **nom de famille** doivent être exacts : le parent en a besoin pour lier l’enfant.

Menu **Enseignants** : invitez un professeur (e-mail, mot de passe temporaire optionnel) ou donnez-lui le **code école** pour qu’il s’inscrive. Assignez-le ensuite à une classe.

## 4. Frais et paiements Wave / Orange Money

Menu **Frais** : définissez les types de frais (scolarité, cantine…) en **FCFA**, avec un jour d’échéance si besoin.

Menu **Paiements** : le parent paie sur **Wave** ou **Orange Money**, puis envoie la capture. Le paiement arrive au statut **PENDING** (en attente).

1. Ouvrez **Paiements**.
2. Consultez la capture (**Voir capture**).
3. **Valider** ou **Rejeter**.
4. Si vous validez, un reçu PDF peut être proposé. Le parent est informé.

> **Important**
> EduConnect ne débite pas le parent tout seul. Vous gardez le dernier mot sur chaque preuve. La validation se fait **en ligne** (pas hors connexion).

## 5. Comptabilité (si le menu apparaît)

Menu **Comptabilité** : comptes Wave, Orange Money, caisse et banque. Recettes, dépenses, catégories, rapport de période, export Excel ou PDF.

Ce menu n’apparaît que si le module est activé pour votre école.

## 6. Messages aux parents

Menu **Messages** (si le module Messages est activé) : liste des conversations. Vous pouvez écrire, joindre un fichier ou un message vocal, et préciser l’enfant concerné.

Les messages restent dans l’application. Ce n’est pas un SMS.

## 7. Devoirs & contrôles (vue direction)

Menu **Devoirs & contrôles** : volumes par matière, calendrier de l’école, liste des publications, export PDF mural ou Excel.

La **publication** des devoirs se fait côté enseignant. Vous pilotez et exportez.

## 8. SMS officiels

Deux conditions, dans cet ordre :

1. EduConnect a activé le module **SMS officiel** pour votre école.
2. Vous avez renseigné l’**identifiant SMS** dans **Paramètres**.

Ensuite, le menu **SMS officiels** montre les envois (absences, retards, paiements, devoirs…) et leur statut.

Sans ce module, les parents reçoivent toujours les alertes **dans l’application** (et e-mail / notification push le cas échéant). Demandez l’activation à EduConnect si vous voulez le SMS au nom de l’école.

> **Wave / Orange Money ≠ SMS**
> Les numéros Wave et Orange Money servent **uniquement** à recevoir l’argent. Ils n’envoient pas de SMS. L’identifiant SMS est un nom d’expéditeur (ou un numéro SMS dédié), déclaré auprès de l’opérateur. Ce n’est pas le numéro de paiement.

## 9. Paramètres

Menu **Paramètres** :

- logo, nom, adresse, ville ;
- **numéro Wave** et **numéro Orange Money** (paiements) ;
- **identifiant SMS officiel**, seulement si le module SMS est activé.

Donnez le **code école** affiché en haut de cette page aux familles et aux enseignants.

## 10. Réinscriptions et année scolaire

Menu **Réinscriptions** : promotions, redoublements, causes, exports PDF / Excel.

Menu **Année scolaire** : année en cours et passage / promotion de classe.

Menu **Emploi du temps** : calendrier des créneaux (si vous l’utilisez).

## 11. Aider un parent bloqué

Le parent a besoin de trois informations **exactes** :

1. le **code école** (Paramètres ou tableau de bord) ;
2. le **matricule** de l’élève ;
3. le **nom de famille** tel qu’il est saisi dans Élèves.

Il se connecte via l’onglet **Parent**, lie l’enfant, puis accepte le bandeau de confidentialité.

Si le lien échoue : vérifiez le code, le matricule et l’orthographe du nom. Pas d’espace superflu.

Si le blocage continue, écrivez à [contact@educonnect.ci](mailto:contact@educonnect.ci).

## 12. Téléphone et coupures réseau

Après une première connexion **en ligne**, vous pouvez enregistrer une classe, un élève ou un enseignant même sans réseau : un bandeau indique « en attente de synchronisation ». Dès que la 4G revient, l’envoi se fait tout seul.

En revanche, **valider un paiement**, importer un CSV ou envoyer un message demande internet.

Sur téléphone : menu du navigateur → **Ajouter à l’écran d’accueil**. Ne videz pas les données du site.
